# ScratchPy – Python Programming Made Easy!

ScratchPy is an application that combines the simplicity of Scratch with the power and flexibility of Python. Its visual programming interface allows you to create programs by assembling blocks, while automatically generating the corresponding Python code.

## Key Features

- **Visual Programming:** Create programs using intuitive, colorful blocks.
- **Real-Time Synchronization:** Switch between visual blocks and Python code, with changes synchronized in both directions.
- **Built-in Python Editor:** View and edit the generated Python code directly.
- **Integrated Execution:** Run your programs and view their output in the built-in console.
- **Library Integration:** Import Python libraries and automatically generate blocks for their functions, classes, and constants.
- **AI Assistant:** Get help, explanations, and suggestions using the integrated Google Gemini AI assistant, ready to use without requiring users to configure their own API key.
- **Block Management:** Move, duplicate, delete, and organize your blocks with ease.
- **Python File Support:** Open existing `.py` files and convert supported parts of their code into visual blocks.

## Who Is ScratchPy For?

ScratchPy is designed for beginners, students, teachers, and anyone curious about programming. Whether you're learning Python for the first time or looking for a more visual way to develop programs, ScratchPy makes coding more accessible.

**ScratchPy: Learn visually, code freely!**
